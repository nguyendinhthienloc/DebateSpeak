# Room Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the sample room routes with one real room flow, from creating a room to the end of a voice or typed debate.

**Architecture:** A Spring Boot `room` package owns room state in PostgreSQL and is the only authority on transitions and time. The React app renders one page at `#/rooms/:id` from a polled room snapshot. LiveKit carries audio behind a small `DebateAudio` interface, and typed turns are saved through the API.

**Tech Stack:** Java 17, Spring Boot 4.1.2, JPA, PostgreSQL 16, H2 (tests only), `io.livekit:livekit-server:0.17.0`, React 18, TypeScript, Vite, `livekit-client` 2.x, Playwright.

**Spec:** [docs/superpowers/specs/2026-11-19-room-flow-design.md](../specs/2026-11-19-room-flow-design.md)
