# PA2 Preview — Project Plan & Vision Document

> **Assignment:** Project Assignment 2 (PA2-2026) | **Weight:** 45 Points | **Duration:** 2–3 Weeks

## Overview of PA2 Requirements

PA2 transitions the team into formal Scrum planning and detailed product positioning:

1. **Part A: Project Plan (15 pts)**
   - Project overview, goals, scope, deliverables, assumptions.
   - Project organization: Team roles & risk management (at least 3 risks with mitigation strategies).
   - Scrum plan: 5 Sprints mapped to PA1–PA5 with Jira integration.
   - Build plan: Incremental test builds planned across all 5 sprints leading to PA5 demo.
2. **Part B: Vision Document (20 pts)**
   - Problem Statement table (*The problem of... affects... the impact of which is... a successful solution would be...*).
   - Product Position Statement table (*For... Who... The product name... That... Unlike... Our product...*).
   - Stakeholder & user descriptions, needs analysis, competition summary.
   - Product features with 3–5 sentence rationales and 1–2 Mermaid workflow diagrams.
   - Quantifiable Non-Functional Requirements (latency, concurrency, security).
3. **Part C: Spec Kit Initialization (5 pts)**
   - GitHub repo setup with Spec Kit in `/src`.
   - `constitution.md` and initialized spec files.
   - Team member training completion logs/evidence.
4. **Part D: AI Usage Report & Weekly Report (5 pts)**
   - Transparent AI usage log following course guidelines.
   - Sprint Planning, 2 Standups, Sprint Review meeting minutes with Jira screenshots.
