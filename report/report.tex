\begin{abstract}
\textbf{DebateSpeak AI} is a web-based, real-time spoken debate and English language learning platform designed for intermediate non-native English learners (CEFR A2--C1). Two human debaters participate in an assigned motion over live WebRTC audio. The platform captures their speech, generates live transcripts with deterministic track-level speaker attribution, and executes an asynchronous multi-agent evaluation pipeline providing CEFR-adapted language feedback, mapping rebuttal structures, and fact-checking claims against web evidence. This report compiles the deliverables for Project Assignment 1 (PA1-2026) under the CS300 Software Engineering curriculum, structured strictly across Parts A, B, C, D, and E.
\end{abstract}

\section{Part B: Project Proposal}
\subsection{Problem Statement \& Target Actors}
Non-native English learners preparing for international speaking tests (IELTS, TOEFL) or global professional careers face a major bottleneck: while reading and writing tools are abundant, real-time live speaking practice with intellectual rigor remains expensive, intimidated by human prejudice, or constrained to solitary flashcard apps. DebateSpeak AI introduces an engaging peer-to-peer live debate platform with intelligent post-debate coaching.

The platform distinguishes two primary actors:
\begin{enumerate}[leftmargin=1.2cm]
    \item \textbf{Debater / Learner (Actor 1):} Registers with a target CEFR level (A2--C1), selects debate topics, joins synchronized live audio rooms, receives live transcripts, and reviews multi-dimensional learning reports with personalized drills.
    \item \textbf{System Administrator / Moderator (Actor 2):} Curates topic motions, monitors room health and AI adapter quotas, audits flagged transcripts, and manages platform safety.
\end{enumerate}

\subsection{Ten Distinctive Functional Groups}
\begin{enumerate}[leftmargin=1.5cm, label=\textbf{FG-\arabic*:}]
    \item \textbf{User Account \& Profile Management:} Argon2id authentication, JWT rotation, and CEFR baseline level tracking.
    \item \textbf{Debate Topic \& Difficulty Management:} Catalog of categorized motions with CEFR difficulty tags and vocabulary suggestions.
    \item \textbf{Debate Room \& Live Session Management:} Finite state machine (\texttt{LOBBY} $\to$ \texttt{READY} $\to$ \texttt{LIVE} $\to$ \texttt{ENDED}), dual-consent gates, and timers.
    \item \textbf{Real-Time Audio Communication:} Managed WebRTC audio routing via LiveKit Cloud, mic test modal, volume meters, and 60-second reconnection handling.
    \item \textbf{Speech-to-Text \& Speaker Attribution:} Dedicated audio track subscription, Silero VAD, streaming STT, and 100\% deterministic speaker tagging.
    \item \textbf{English Language Analysis:} Spoken metrics (WPM, pause profiles, filler rates) and quote-grounded grammar/vocabulary feedback.
    \item \textbf{Argument \& Debate Analysis:} Extraction of claims, rebuttals, concessions, and logical fallacies.
    \item \textbf{AI Fact-Checking \& Evidence Analysis:} Search API integration, sanitized snippet extraction, and 5-level verdict generation with uncertainty indicators.
    \item \textbf{Multi-Agent Evaluation \& Consensus:} Independent Evaluator and Skeptic agents, Debate Judge scoring, and deterministic consensus calculation.
    \item \textbf{Learning History \& Personalized Reports:} Multi-dimensional learning reports with personalized practice drills and historical skill progression charts.
\end{enumerate}

\subsection{Standalone AI-Powered Capabilities}
DebateSpeak AI features an asynchronous Multi-Agent Evaluation Arena. Following a live debate, participant audio transcripts are processed through specialized agents:
\begin{itemize}[leftmargin=1.2cm]
    \item \textbf{Strict Quote-Grounding Rule:} Feedback items cite exact verbatim quotes from the learner's transcript. The system rejects ungrounded or hallucinated learner errors.
    \item \textbf{Automated Fact-Checking:} Check-worthy factual claims trigger web retrieval, returning verified sources, 5-level verdicts, and confidence indicators.
\end{itemize}

\subsection{Key Competitive Differentiators}
DebateSpeak AI bridges the gap between competitive debate and pedagogical language training:
\begin{enumerate}[leftmargin=1.2cm]
    \item \textbf{Real-Time Peer Synergy:} Synchronous voice debate over WebRTC creates genuine conversational pressure unlike solitary AI speaking bots.
    \item \textbf{Multi-Dimensional Feedback:} Pairs rhetorical analysis (rebuttals, fallacies) with fine-grained English metrics (WPM, pause profiles, CEFR lexical suggestions).
\end{enumerate}

\begin{itemize}[leftmargin=1.2cm]

\begin{itemize}[leftmargin=1.2cm]
